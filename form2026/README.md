# Форма записи на пробный урок

Страница: `guitardo.ru/form2026`

## Состав

- `index.html` — разметка формы
- `style.css` — базовые стили (без дизайна, для теста)
- `script.js` — маска телефона, валидация на клиенте, отправка через fetch
- `send.php` — серверный обработчик, отправляет письмо на `ag@guitardo.ru`

## Деплой по FTP

Загрузить содержимое этой папки в директорию `form2026` в корне сайта на хостинге
(так, чтобы файлы были доступны как `guitardo.ru/form2026/index.html` и т.д.).

## Требования хостинга (этап 1 — отправка на почту)

- PHP 7.4+ с включённой функцией `mail()`.
- Ящик `ag@guitardo.ru` должен существовать и принимать почту.
- Желательно настроенные SPF/DKIM для домена `guitardo.ru`, иначе письма от
  `mail()` могут попадать в спам. Если письма не доходят — проверьте папку
  "Спам" и логи почтового сервера хостинга.
- В `send.php` в константе `FROM_EMAIL` указан `noreply@guitardo.ru` — этот
  адрес должен быть в домене вашего хостинга (некоторые хостинги блокируют
  `mail()`, если From не совпадает с доменом сайта). При необходимости
  создайте почтовый ящик `noreply@guitardo.ru` или замените на реальный.

Если `mail()` не будет надёжно доставлять письма (частая ситуация на
хостингах без настроенного почтового сервера), на втором шаге можно
переключить `send.php` на отправку через SMTP (например, через сам ящик
`ag@guitardo.ru`, если он на этом же хостинге) — понадобятся логин и пароль
почтового ящика.
