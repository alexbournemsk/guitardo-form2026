# Форма записи на пробный урок

Страница: `guitardo.ru/form2026`

## Состав

- `index.html` — разметка формы
- `style.css` — базовые стили (без дизайна, для теста)
- `script.js` — маска телефона, валидация на клиенте, отправка через fetch
- `send.php` — серверный обработчик, отправляет письмо на `ag@guitardo.ru` через SMTP (PHPMailer)
- `config.php` — настройки: адрес получателя и SMTP-доступы почтового ящика-отправителя
- `vendor/phpmailer/` — библиотека PHPMailer (нужна для отправки через SMTP)

## Деплой по FTP

Загрузить содержимое этой папки (включая `vendor/`) в директорию `form2026` в
корне сайта на хостинге (так, чтобы файлы были доступны как
`guitardo.ru/form2026/index.html` и т.д.).

## Настройка отправки почты (обязательно перед запуском)

Изначально письма отправлялись через стандартную функцию PHP `mail()` — она
проще, но чаще всего именно из-за неё письма попадают в спам: у `mail()` нет
авторизации, IP-адрес хостинга может быть в спам-базах, и заголовки не
проходят проверки SPF/DKIM/DMARC у Gmail/Mail.ru/Яндекса.

Поэтому форма теперь отправляет письма через SMTP — то есть авторизуется как
реальный существующий почтовый ящик на вашем домене, как обычный почтовый
клиент. Это сильно повышает доставляемость (но не гарантирует её на 100%,
см. ниже).

Почта на домене `guitardo.ru` размещена в Яндекс.360, поэтому SMTP настроен
именно под него:

- Сервер: `smtp.yandex.ru`
- Порт: `465` (SSL, уже указан в `config.php`)
- Логин: полный адрес ящика, например `noreply@guitardo.ru`
- Пароль: **не обычный пароль от почты**, а пароль приложения — Яндекс
  требует его отдельно для SMTP/IMAP-доступа

**Что нужно сделать:**

1. Создайте (или используйте существующий) почтовый ящик на домене
   `guitardo.ru` в Яндекс.360, например `noreply@guitardo.ru`.
2. Зайдите на `id.yandex.ru` под этим ящиком → «Безопасность» → «Пароли
   приложений» → создать новый пароль приложения типа «Почта». Скопируйте
   его (показывается один раз).
3. Откройте `config.php` и впишите этот пароль в `SMTP_PASSWORD`, а логин —
   в `SMTP_USERNAME` (если ящик отличается от `noreply@guitardo.ru`).
4. Если у организации в Яндекс.360 ограничен доступ к почте по протоколам —
   зайдите в `admin.yandex.ru` (панель администратора организации) → Почта
   → Настройки, и разрешите доступ по IMAP/SMTP для ящика.
5. Убедитесь, что PHP на хостинге умеет открывать исходящие соединения по
   порту 465 (на большинстве хостингов это разрешено по умолчанию).

**Если письма всё равно попадают в спам после переключения на SMTP:**

- Проверьте в панели хостинга, что для домена `guitardo.ru` включены и
  настроены записи **SPF**, **DKIM** и **DMARC** (обычно это делается одной
  галочкой в разделе "Почта" / "DNS" панели хостинга). Без них почтовые
  сервисы будут подозрительны даже к письмам, отправленным легитимно через
  SMTP.
- Проверьте результат через https://www.mail-tester.com — отправьте туда
  тестовую заявку и посмотрите оценку и рекомендации.
- Попросите первых получателей (например, ag@guitardo.ru в Gmail/Яндексе)
  вручную пометить письмо как "Не спам" — это ускоряет накопление
  репутации адреса.
